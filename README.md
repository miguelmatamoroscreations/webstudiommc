# Web Studio MMC 🎨

Sitio web profesional para **Web Studio MMC** - Diseño y desarrollo de páginas web de calidad para negocios.

## 📋 Descripción

Este proyecto es una página web moderna y responsive diseñada para mostrar los servicios y portafolio de Web Studio MMC. Incluye secciones de servicios, portafolio de proyectos y formulario de contacto.

## 🚀 Características

- ✅ Diseño **responsive** (móvil, tablet, desktop)
- ✅ Navegación suave y moderna
- ✅ Sección de servicios
- ✅ Portafolio de proyectos
- ✅ Formulario de contacto
- ✅ Efectos visuales y animaciones
- ✅ Optimizado para SEO

## 📁 Estructura del Proyecto

```
webstudiommc/
├── index.html          # Página principal
├── css/
│   └── styles.css     # Estilos personalizados
├── js/
│   └── script.js      # Scripts funcionales
├── assets/            # Imágenes y recursos
├── package.json       # Configuración del proyecto
├── .gitignore         # Archivos a ignorar
└── README.md          # Este archivo
```

## 🛠️ Instalación

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/miguelmatamoroscreations/webstudiommc.git
   cd webstudiommc
   ```

2. **Abrir en el navegador:**
   - Opción 1: Abre directamente `index.html` en tu navegador
   - Opción 2: Usa un servidor local:
     ```bash
     python -m http.server 8000
     # Luego abre: http://localhost:8000
     ```

## 📝 Personalización

- Edita `index.html` para cambiar contenido y estructura
- Modifica `css/styles.css` para personalizar estilos y colores
- Añade tu lógica en `js/script.js`
- Guarda imágenes en `assets/`

## 🌐 Publicar en GitHub Pages

1. Ve a Settings > Pages
2. Selecciona `main` como rama
3. Tu sitio estará disponible en: `https://miguelmatamoroscreations.github.io/webstudiommc`

Para más información sobre Web Studio MMC, contacta a través del formulario en la web.
